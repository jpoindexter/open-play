# Hercules MIDI semantics correction — plan84, 17 October2026

The current [official MK2 Pro quickstart](https://support.serato.com/hc/en-us/articles/10173727435151-Hercules-DJControl-Inpulse-300-MK2-Quickstart-Guide) is the behavior reference, not the custom Mixxx implementation. Its primary pad modes are Hot Cue, Auto Loop, Stems and Sampler; shifted modes include Pitch Play, Manual Loop, Loop Roll and Scratch Bank. Shift-Q changes tempo range; Shift-Cue loads the previous track. Sampler Shift stops a loaded sample or loads an empty slot. These are documented claims, not new installed-reference or physical tests.

Address facts are separate from behavior. The previously inspected authored MK2 XML has primary Sampler notes0x30–0x37 and cue-clear notes0x08–0x0F on pad channels, and standard transport/modifier addresses used in v4. No controller script was copied. The proposed Sampler-alternate range0x38–0x3F is an **inferred adjacent-bank hypothesis**: it is not present in that inspected XML and has not been captured from this unit. Both decks addressing the selected Open Play Sampler bank is the independent implementation policy, pending physical/reference comparison. Synthetic injection proves the software action, not those physical bytes.

v4 has132 candidate address assignments. It adds per-deck Quantize/Slip, tempo-range selection, previous/stutter, cue clear and eight shared selected-bank Sampler targets plus alternate stop/load targets. Auto Loop/Roll, Stems, Pitch Play, Manual Loop and Scratch Bank hardware pad-bank routing remain open; their documented names must not inherit community Mixxx actions for the same pages. Browser/crate focus, Prepare controls, Instant Double, Shift tempo ignore/fader start/cue-tap, guide/LED feedback, full FX behavior and other remaining hardware rows remain in the full plan. No full default-map acceptance or paywall bypass is claimed. Local native test approval is already given; the currently open0.1.12 build is unchanged by plan84 browser edits.
