# Reviewed interaction requirements

This growing specification currently covers selected display, DJ preferences, sync, FX, sampler, MIDI and expansion articles. It is **not the full interaction inventory**. Each requirement has an explicit trigger, expected result and evidence boundary. Browser simulation is planned, not implemented. Native work remains blocked on prototype approval.

Codex and Claude Code model/effort recommendations are embedded per requirement in the JSON companion, inherited from its parent feature. These recommendations do not claim either model has been invoked.
