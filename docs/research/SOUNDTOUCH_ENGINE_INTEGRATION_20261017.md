## Implemented and exercised

`experiments/keylock-soundtouch/window-source.mjs` adds contiguous half-second PCM chunks, immutable geometry, bounded retention, whole-chunk drop, true-duration authority and atomic append/read/drop validation. Incoming channels must occupy their full backing buffers so tiny subarrays cannot hide whole-file retention. Payload accounting excludes decoded caller-owned AudioBuffers, JavaScript and opaque DSP allocations. Missing retained history/future is CoverageError; only the declared original endpoint permits zeros. Explicit protected cursors prevent removing PCM still needed by prepared/active/retiring epochs.

The actual public DSP transport accepts that source without changing pitch/stretch algorithms. At44.1/48k, eight seconds of128-frame pulls from a repeatedly dropped/refilled four-second source window are bit-identical to whole-source transport. Out-of-window preparation rejects without changing the queued owner/generation. The six source-contract checks and two real-DSP comparisons pass8/8 after missing-feature RED0/8 and store-only6/8. Existing functional13, boundary6, descriptor2, no-performance2 and independent transport6 checks pass on the updated transport. These are serial checks, not browser/device acceptance.

`node-controller.mjs`, `node-worklet.mjs`, `node-factory.mjs` and the separately named `live-adapter.js` implement the existing low-level AudioNode interface: latency/addBuffers/dropBuffers/schedule/stop/dispose plus real connect/disconnect. Duration is explicitly supplied relative to a fixed group origin; append extent is not EOF. Effective semitones from the existing adapter are applied once, using transport keylock=true. Scheduled stop is replaceable rather than terminal. Disposal acknowledges processor release, rejects pending work and cannot revive the node. The reported0.12s latency value is a preparation-lead budget, not measured audible/physical delay.

The six serial protocol cases initially fail0/6 as missing functionality. First implementation gives5/6: a multichannel test incorrectly expected the same550Hz channel to have identical phase when paired with different left channels. Independent stereo WSOLA pairs can choose different overlap offsets. Original failed report (`soundtouch-node-protocol-green.json`, despite its misleading filename) is preserved; corrected oracle compares all eight channels bit-for-bit to whole-source DSP and passes6/6. This does not establish coherent spatial phase across independent pairs.

The existing SRC, absolute phase,32tap/1024phase coefficients, caller/source ownership, stable outputs, operation queue,40ms warm follow and grouped crossfade logic are retained from the selected adapter. Only the experimental factory/options, window preflight and explicit experimental policy labels differ. Production `prototype/engine.js` is served unchanged and actually executes start/setPitch/setRate/seek/pause/start; its dynamic adapter URL is mapped to the separately named candidate. The test context constructor requests a declared sample rate and is immediately restored. This fixture boundary is recorded; it is not default-device/native acceptance.
