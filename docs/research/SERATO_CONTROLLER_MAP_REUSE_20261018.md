## Import pipeline implemented so far

`scripts/import_serato_maps.py` discovers XML in explicitly supplied files/folders, parses bounded UTF-8 XML without DTD/entity declarations, retains every control/condition/lighting branch and emits a private normalized catalog. It deduplicates byte-identical source files by SHA256 and refuses to overwrite earlier outputs. Only known MIDI encoding, deck/slot, input-event and translation behaviors generate Open Play mappings. Unknown conditions, static/toggle variants, encodings, output messages and extra attributes remain explicit issues; they are not silently converted to guessed actions. It never guesses a hardware identity from a MIDI channel and leaves profiles unbound.

Six focused parser checks executed malformed/entity/depth rejection, channel/note limits, extra-attribute handling, retained conditions/LED branches, correct zero-based deck translation, and batch/symlink discovery. Three focused production preset/router checks executed the Hercules direction regression and existing pickup/relative Sync policies. These are parser/engine-collaborator evidence, **not browser import/automatic matching, actual audio or all-controller acceptance**. ## Source and status policy

Product source labels: **Official Serato**, **Alternative mapping — named source**, **User mapping**. An author-posted Serato XML is an alternative/custom Serato map, not an official factory default. A map's schema alone cannot establish vendor authorship. Source labels and runtime acceptance are independent: source found → parsed → translated → bound → exercised; factory equivalence and physical confirmation remain separate.

Official Serato describes the [MIDI folder's XML as custom mappings](https://support.serato.com/hc/en-us/articles/219871867-Merging-Two-or-more-Serato-Folders), [presets as saved assignments](https://support.serato.com/hc/en-us/articles/224914007-Presets), and [default restoration as unloading custom XML](https://support.serato.com/hc/en-us/articles/209377487-MIDI-mapping-with-Serato-DJ-Pro). The latter also excludes jogs/platters, input switches, Shift and performance-pad mode buttons from normal remapping and names non-remappable accessories. Therefore exported custom XML cannot by itself prove recovery of every factory control, HID protocol or lighting behavior.

Author-posted schema examples: [Behringer CMD DC-1](https://gist.github.com/mathieuaime/7be3d51931b6fe65b6909bd8211878a3), [Allen & Heath K2](https://gist.github.com/monk-topmonks/7961220a41ccb37dea914fe4f7653c65), [DJM-S9 custom map repository](https://github.com/marscanbueno/serato-dj-pro-midi-maps). Alternative application datasets: [Mixxx controller sources](https://github.com/mixxxdj/mixxx/tree/main/res/controllers), [OpenFadeR-Map](https://github.com/OpenRsG/OpenFadeR-Map). Their formats, dependencies and source licenses remain individually relevant; source collection is not a compatibility or redistribution decision.
