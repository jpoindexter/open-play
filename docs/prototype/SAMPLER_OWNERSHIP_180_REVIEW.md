## Criterion and reference limit

It does not define our asynchronous backend-creation/future-start transaction boundary. This checkpoint establishes independent user-intent/commit consistency and actual cancellation behavior, not exact vendor race equivalence. In particular source Stop is not treated as an implicit deck Stop. Before future position selection an invalid source can reject alignment; after a current deck start has successfully scheduled, a source-only Stop must not leave that playing deck falsely armed. Explicit deckStop/load always revokes that deck's request. The broader before-scheduling source-loss policy and replacement race remain open.
