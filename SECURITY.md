# Security reports

Please report security vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/jpoindexter/open-play/security/advisories/new).

Include the affected source revision, a minimal reproduction, impact and any relevant environment details. Do not attach credentials, private libraries, songs or full profile backups. Use generated or redacted data whenever possible.

Ordinary playback, Sync, waveform and interface defects belong in [Issues](https://github.com/jpoindexter/open-play/issues/new/choose). Do not disclose a security vulnerability there while it is being investigated.

## Supported scope

Open Play is pre-release. Security fixes target the current development branch; older private desktop candidates are not maintained release channels. A public binary release and its support window will be announced separately.

We will assess reports and coordinate an appropriate fix and disclosure. There is no guaranteed response deadline or bounty program.
