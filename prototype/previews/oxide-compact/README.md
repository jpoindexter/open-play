# Oxide compact study

Separate visual preview requested28October2026. Serve the existing repository on a dedicated loopback port, then open `/prototype/previews/oxide-compact/`. Example: `python3 scripts/serve_prototype.py --port 18848`. The dedicated origin has its own demo session/cache and does not share the desktop profile or original music. Do not point this wrapper at a live personal session.

Reuses the actual workspace in an iframe; one scoped theme file and one small preview controller. No current-app imports or desktop package changes. Oxide-inspired palette/type treatment, adapted to the requested blue accents follows the user’s Refero reference using installed system font substitutes, without copying proprietary assets/fonts. Compact Play/Cue are24logical pixels; header icons14. Filter ranges remain in their original delegated event owner, visually removed from the mixer and exposed by Color FX (Escape closes/returns focus). RGB frequency colors, core controls and library previews remain.

Overviews display the upper measured energy envelope as a one-sided preview. Large scrolling waveforms retain their original renderer. This is an isolated presentation experiment, not the vendor waveform algorithm. The preview starts muted with generated demo tracks; no audible/native/hardware validation is claimed. Fit view is a visual overview in narrow panels; use100%view to inspect/interact at actual sizing. The current desktop remains0.1.92with its previously delivered envelope repair; no Oxide/filter/sizing experiment is applied to it.
