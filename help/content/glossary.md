## Tempo and timing

| Term | Meaning |
|---|---|
| BPM | Beats per minute: how quickly beats repeat. Base BPM and playback BPM can differ. |
| Beat | A recurring pulse used for timing. |
| Downbeat | The first beat of a bar. |
| Bar | A group of beats; this grid displays four-beat bar positions. |
| Phase | Relative beat position between songs. Equal tempo does not guarantee equal phase. |
| Phrase | A larger musical section. Matching beats does not automatically match phrases. |
| Beatgrid | The timing map drawn over a song and used for grid-based actions. |
| Warp marker | A point after which the grid uses a different tempo while beat position remains continuous. |
| MASTER | The reference deck used for a Sync relationship. |
| Nudge / pitch bend | A temporary speed change used to adjust phase; release returns to selected tempo. |

## Decks and sound

| Term | Meaning |
|---|---|
| Temporary Cue | A deck position used for hold-to-audition and return-on-release. |
| Hot cue | A saved jump/audition point on a performance pad. |
| Headphone CUE | Channel selection for the separate monitor bus, unrelated to setting a transport cue. |
| Pitch / TEMPO | Speed adjustment; without pitch preservation, speed also changes musical pitch. |
| Key Lock / MT | Processing intended to retain pitch while speed changes. |
| Key shift | Musical pitch change measured in semitones. |
| Trim / gain | Input-level adjustment on a channel. |
| EQ | Controls for low, mid and high frequency ranges. |
| Filter | Frequency-selective shaping, such as low-pass or high-pass. |
| Clipping | Signal exceeding a stage’s available headroom; raising level is not always safe. |
| Crossfader | Horizontal control blending channels assigned to its two sides. |
| Quantize | Aligning supported actions to grid timing; it depends on grid accuracy. |

## Library and recording

| Term | Meaning |
|---|---|
| Crate | A library collection of songs. |
| Smart crate | A collection defined by metadata rules. |
| Overview / preview | Whole-track visual summary, unlike the zoomed detailed waveform. |
| Session-only | Usable now but not confirmed durably saved for the next launch. |
| Metadata backup | Application data such as crates, settings, cues and grids; contains no audio or recordings. |
| Master capture | A downloaded recording of the master audio stream. |
| Fixture / simulation | A demonstration state rather than a connected real service or device. |
