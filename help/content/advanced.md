## Read feature status first

Open Play keeps advanced surfaces available while core mixing is developed. The categories below explain entry points and limits; they are not complete audible/device acceptance of every parameter or combination. Use **Feature status** and visible badges for the current implementation boundary.

## Effects

Open **FX** to choose effect banks, routes and parameters. Inspect which deck/master a bank targets before enabling it. Dry/wet, individual parameters and tempo/multiplier controls affect the selected bank.

Keep output low when trying feedback or resonant effects. Automatic/Tap/manual tempo behavior is bank-specific. The visible effect catalog is broader than the set with complete audible parity acceptance; do not infer that every label reproduces another app’s DSP.

## Sampler

Open **Sampler** from Performance panels. Select a bank, load a song into a slot and choose **Trigger**, **Hold** or **On/Off**; Repeat is a separate option. Output can target Master or a deck bus.

Use each slot’s Stop or **Stop all samples** before ending a session. Decks being paused does not prove every sample is stopped. Current keyboard slots are **Z X C V B N M ,**; Option + the key stops a slot. Slot Key Lock and Sync can require preparation.

## Stems

Open **Stems preparation** for the local preparation workflow. Stems require optional local model/backend setup; this help site supplies no model or hosted stem service. Keep the original track and read job/error state before playback.

Desktop upload, long-track preparation and model/runtime combinations have separate acceptance work. A Stems pad or entry in a crate is not proof a separation job finished successfully.

## Pitch, Slicer and Scratch banks

**Pitch** pads change cue pitch with held-action rules; **Slicer** uses timed regions; **Scratch banks** load saved slot assignments into a focused deck. Inspect deck focus, source cue and repeat/key settings before triggering.

Hardware bank workflow, jog/touch behavior and every pitch/time-stretch combination remain mode-specific. Long-file/key-shift/Reverse processing can reach the render memory limit.

## Flip and automation

Flip records timed cue/reverse-style events and provides per-track saves and playback controls. Stop/disable automation before diagnosing a transport change you did not intend. Native metadata compatibility and exact timing parity are not established.

## Video and recording

Local video surfaces include two-source mixing, overlays and capture tools. Codec support, karaoke formats, HD output, Syphon and the full effect/transition catalog are incomplete or unverified. Audio-only master recording has its own [guide](/recording/).

## Simulated services

Provider catalogs/sign-in/cache states, Link peers/network state and external DVS/HID/Phase fixtures are demonstrations, not real connected services. No subscription, provider catalog or networking connection is created by their simulated controls.

Prefer the verified local-audio path for a practical set. [Known issues](/known-issues/) distinguishes remaining core risks from these advanced limits.
