## Open and navigate Settings

Use the header’s **Settings** control. Tabs remain available while scrolling. Nested pages opened from Setup have **Back to Settings**; closing the dialog returns to the workspace.

The header **Layout and display settings** shortcut opens Layouts directly. Exact options can differ across builds. A preference being visible does not establish that its native/device service is implemented.

## Layouts

- Choose among the six available layout styles.
- Set Horizontal/Vertical detailed waveforms.
- Choose Compact/Full decks and Wave size.
- Switch Day/night where offered.
- Reset display/workspace style when you want the layout defaults.

Display reset is distinct from resetting a knob or deleting library data. Hiding a mixer, deck or panel does not stop its audio.

## Audio

Use **Audio devices and routing** for real output enumeration/selection and stereo/four-channel routes. Follow [Mixer and headphones](/mixer/#configure-a-separate-output).

The **Link session** surface is simulated. It does not join an Ableton Link network. Buffer/sample-rate/native configuration controls require actual device/runtime support; do not treat a fixture preference as confirmed hardware calibration.

## Mixer

Mixer preferences include supported curve and EQ behavior. Choose a channel/crossfader response deliberately and listen at low volume. Changing a curve changes how control position relates to level; it does not reset every channel state.

Inspect EQ boost/range options before comparing full-cut/full-boost behavior. A neutral knob position and an audible matched level are different concepts.

## DJ and keyboard behavior

Settings include playback-related options, including **Playback Keys Use Shift**. When enabled, playback shortcuts require Shift or Caps Lock. This is useful for avoiding accidental commands while navigating, but input/dialog guards still apply.

Sync mode matters: [Simple and Smart Sync](/sync/) have different paused/playing rules. Do not assume changing a preference instantly repairs a track’s inaccurate grid.

## MIDI and Advanced

**MIDI → Mapping editor** opens input/mapping tools. Current device compatibility and full mappings need [hardware verification](/midi/).

**Advanced** holds feature status and diagnostics/storage tools. Treat explicitly simulated providers, external controls and file actions as demonstrations. Diagnostics can contain private paths or metadata; review before sharing.
