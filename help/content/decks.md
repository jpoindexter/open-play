## Load and transport

Select a library song and press the intended deck’s **Load**. Wait for preparation before playback. Loading a replacement cancels pending temporary-Cue ownership; never depend on a held key to continue across a track replacement.

| Control | What it does |
|---|---|
| Play / pause | Starts or pauses that deck. A moving timer indicates transport, not necessarily audible master output. |
| CUE | Sets/auditions the temporary cue; [release and latch rules](/cues-loops/#temporary-cue) differ from Play. |
| Eject | Removes the loaded track from the deck. Keep the original file and downloaded recordings independently. |
| Overview waveform | Seeks within the full song. Seeking a playing song can make an abrupt musical change. |
| Repeat | Enables repeat behavior; turn it off when checking a clean end/stop. |
| Reverse / Censor | Reverse changes direction; held Censor is momentary. Advanced pitch/Reverse combinations have limits. |

The **INT / REL / ABS / THRU / WIR** selector includes external-control fixtures. It does not prove a connected DVS/HID/Phase system. Use INT for the local-audio workflow.

## Tempo and pitch range

The deck’s **TEMPO** fader changes playback speed. Read both its percentage and the displayed BPM. A song’s estimated base BPM and its current playback BPM are different values.

Turn Sync off before manual matching. With Smart Sync, the first OFF can retain relative tempo; a further OFF restores controller-pitch behavior. Explicitly reset TEMPO to 0% when starting a new manual check.

Use the fader’s labelled scale and cap to judge position. Use keyboard arrows on a focused fader for small changes where supported. A focused fader consumes its own keyboard interaction; click the track title before using deck shortcut keys.

## Jog and scratch

Hold **T / Y** to temporarily slow/speed the left deck; **G / H** controls the right. Release returns to its selected tempo. These are temporary nudges, not permanent BPM edits.

The platter supports dragging to scratch in supported views. A waveform drag seeks the song and is a different gesture. Shift-drag gives a finer waveform adjustment; Escape cancels that interaction where available.

## Key Lock and key shift

**Key Lock / MT** aims to preserve pitch as speed changes. Key shift changes musical pitch separately. It can require audio preparation; wait for the status instead of repeatedly clicking.

Long-file, key-shift and Reverse combinations can reach a pitch-render memory limit. Preserve the song and report the exact warning. Visibility of these controls does not establish every combination’s audible behavior. [Known limitations](/known-issues/#pitch-reverse-and-advanced-audio) apply.
