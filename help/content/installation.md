## Get the correct build

Open Play currently has private Mac test builds. There is no approved public beta installer or download on this site. Use a build supplied by the project owner and check its version in the window title.

The current private package targets **Apple Silicon (arm64)**. An Intel build and a fully tested macOS compatibility range are not established. Do not infer support for an OS merely because it can open the application.

## Open safely

1. Keep a separate copy of your original songs.
2. Open the supplied Open Play build. Avoid opening a second instance or another build against the same profile.
3. Lower your output volume before starting playback.
4. Follow [Your first mix](/first-mix/) using two local songs.

The private package is not a signed/notarized public distribution. If macOS blocks it, stop and ask the person who supplied it for the intended distribution procedure. Do not disable Gatekeeper or macOS security to follow this manual.

## Before upgrading or restarting

1. Pause every deck and stop Sampler playback.
2. Stop and download any recording you need. An unfinished or undownloaded capture must not be treated as saved.
3. Check **Files** for session-only audio and retry local storage where offered.
4. Export your current metadata backup and keep originals separately.
5. Quit normally before opening a replacement build. Keep a recoverable profile copy when following an owner-supplied upgrade procedure.

Private upgrade observations do not establish every clean-machine install, crash, downgrade or migration path. Avoid alternating versions against one live library.

## Removing a private build

Quit the application normally before moving its application bundle to Trash. Removing the app is separate from removing your user profile or music. Do not delete application data to troubleshoot missing tracks; preserve it for recovery first.

Public installation, update, rollback and uninstall instructions will be expanded when that distribution is verified. [Current beta limitations](/known-issues/) remain authoritative.
